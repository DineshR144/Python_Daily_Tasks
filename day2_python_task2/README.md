# Even or Odd Checker

A simple Python program that accepts an integer from the user and determines whether the given number is even or odd using the modulus operator.

## Features

* Accepts an integer as user input
* Checks the number using the modulus operator
* Displays whether the number is even or odd

## Technologies Used

* Python

## Example

```text
Enter a value: 10
even
```

## Learning Objective

This task demonstrates user input, conditional statements, and the modulus operator in Python.
