# Battery Status Checker

A simple Python program that takes the current battery percentage as input and provides a charging recommendation based on the battery level. It also calculates the remaining percentage required to reach full battery capacity.

## Features

* Accepts the current battery percentage from the user
* Provides charging recommendations based on battery level
* Displays the current battery percentage
* Calculates the remaining percentage to reach 100%
* Demonstrates conditional statements and arithmetic operations

## Technologies Used

* Python

## Example

```text
Enter your current battery percentage: 35
low-normal charging
battery capacity 60kwh
current: 35 %
desired: 65 %
```

## Learning Objective

This task helps practice Python user input, conditional statements, arithmetic operations, and output formatting.
