# Python Calculator

## 📌 Project Overview

The **Python Calculator** is a beginner-friendly console-based application developed using Python. It performs basic arithmetic operations based on the user's selected option.

The program uses functions to perform calculations and conditional statements to determine which operation to execute.

## ✨ Features

* **Addition (+)** – Adds two numbers.
* **Subtraction (-)** – Subtracts the second number from the first.
* **Multiplication (*)** – Multiplies two numbers.
* **Division (/)** – Divides the first number by the second.
* **Modulus (%)** – Returns the remainder after division.
* **User Input** – Accepts the operation choice and two numbers.
* **Invalid Option Handling** – Displays an invalid option message when the user enters an unsupported choice.
* **Function-Based Structure** – Uses separate functions for each arithmetic operation.

## 🛠️ Technologies Used

* **Python 3**
* Python functions
* Conditional statements (`if`, `elif`, `else`)
* User input using `input()`
* Type conversion using `int()`

## 🚀 How to Run the Project

### Prerequisites

Install Python 3 on your computer.

### Steps

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code or a terminal.
3. Save the Python code as `calculator.py`.
4. Run the following command:

```bash
python calculator.py
```
